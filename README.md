# TheFirstIstari.github.io

Personal portfolio site for TheFirstIstari, hosted via GitHub Pages.

## Structure

- `index.html` — landing page with featured projects and embedded demo.
- `projects.html` — searchable/filterable project detail cards.
- `assets/images/` — local thumbnails and visuals.

## Local preview

Open either HTML file directly, or run a lightweight local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
